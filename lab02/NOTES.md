Рабочая папка - место где мы меняем файлы
Индекс - зона подготовки файлов к сохранению
Коммит - сохраненный снимок истории проекта
Различие GIT и GitHub:
Git - это программа на компьютере
GitHub - это сайт для хранения репрезиториев
Использованные команды: 
git status — показывает текущее состояние файлов и папок в репозитории. 
git diff — сравнивает изменения в рабочей папке с индексом. 
git diff --staged — сравнивает изменения в индексе с последним коммитом.
